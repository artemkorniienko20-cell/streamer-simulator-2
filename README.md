# 🎮 Streamer Simulator 2 (Стрімер Симулятор 2)

> 3D браузерний симулятор життя стрімера з відкритим містом, реалістичною фізикою авто у стилі GTA 5, кастомізацією ПК, магазинами та симуляцією трансляцій.

---

## 🌟 Основні можливості (Features)

- 🏙️ **Відкритий 3D світ (Los Santos Vibe)**:
  - Процедурний сонячний SkyDome з м'якими тінями та пальмами.
  - Повноцінна дорожня мережа: перехрестя, світлофори, пішохідні переходи, дорожні знаки, білборди та міський парк із фонтаном.
  - Пост-процесинг у стилі GTA 5 (Unreal Bloom, Color Grading, віньєтування, Dynamic Speed Blur).
- 🏍️ **Транспорт та фізика GTA 5**:
  - Початковий байк біля АЗС "ОККО".
  - Автосалон "Авто-Мрія": від старого іржавого «Запорожця / Копійки» до гіперкара Cyber Beast Edition.
  - Справжні промені фар SpotLight, інтерактивні стоп-сигнали, занос та дрифт з димом з-під коліс (`Space`), вереск гуми та автомобільний сигнал (`H`).
  - Радіостанції GTA 5 у салоні авто (`R`): Radio Los Santos, Nightride FM.
- 🎥 **Режими камери**:
  - Вільне перемикання між видом від **1-ї особи** (з прицілом-крапкою та рухом голови) і **3-ї особи** на клавішу **`V`**.
- 🏪 **Інтерактивні магазини**:
  - 🛒 **Супермаркет «Сільпо 24/7»** — смачна піца, київська шаурма, карамельний лате та енергетики "Non Stop" для відновлення Stamina.
  - 🎙️ **Магазин техніки «Rozetka Девайси»** — студійні мікрофони, кільцеві RGB лампи, геймерські крісла та 4K вебкамери, що збільшують приріст глядачів і суми донатів.
  - 👕 **Бутік «Drip Store»** — зміна 3D скіна персонажа: худі "Київський Дріп", кіберпанк неон, золотий бомбер та окуляри Thug Life.
  - 🔧 **Автомайстерня «СТО West Coast»** — встановлення Nitro Boost (прискорення на `Shift`), неонове підсвічування днища (пурпур / блакитний) та кастомне фарбування кузова.
- 💻 **Кар'єра стрімера**:
  - Початковий капітал: рівно **100 ₴**.
  - Купівля першого комп'ютера **"Old Comp"** за 100 ₴ з ретро-CRT монітором та системником з горища.
  - Апгрейд сетапу: Офісний ПК -> Геймерський -> Pro Streamer -> Ultra Cyber Beast 5090.
  - Запуск стрімів, вибір категорій ігор (Ретро Танчики, Minecraft UA, CS2, Dota 2, Cyberpunk 2077).
  - Живий динамічний чат глядачів та донати з озвученням та повідомленнями.
- 📱 **Смартфон (на клавішу `P`)**:
  - Баланс Монобанку з історією транзакцій.
  - Магазин ПК, Автосалон, Сільпо, Rozetka, Drip Store, СТО Тюнінг.
  - Панель керування стрімом.
- 🗺️ **Навігація**:
  - Міні-карта у стилі GTA 5 зі смугами Health, Armor, Stamina.
  - Повна інтерактивна карта міста на клавішу **`M`**.

## 🕹️ Керування (Controls)

| Дія | Клавіша |
|---|---|
| **Рух персонажа / Керування авто** | `W`, `A`, `S`, `D` |
| **Огляд камерою** | Мишка (вільний огляд) |
| **Спринт (пішки) / Nitro Boost (в авто)** | `Shift` |
| **Стрибок / Ручне гальмо (Дрифт)** | `Space` |
| **Дія** (сісти в авто / зайти в магазин / сісти за ПК) | `E` |
| **Перемикання виду (1-ша / 3-тя особа)** | `V` |
| **Відкрити / закрити смартфон** | `P` |
| **Відкрити повну карту міста** | `M` |
| **Радіостанції GTA 5** (у транспорті) | `R` |
| **Автомобільний сигнал (клаксон)** | `H` |

---

## 🛠️ Технологічний стек (Tech Stack)

- **Frontend**: HTML5, CSS3, Vanilla TypeScript
- **3D Engine**: [Three.js](https://threejs.org/)
- **Post-Processing**: Three.js EffectComposer (UnrealBloomPass, ShaderPass)
- **Audio Engine**: Web Audio API (процедурний синтез реву двигуна, клаксона, вереску шин та радіостанцій)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)

## 🚀 Як запустити локально (Getting Started)

1. **Клонуйте репозиторій**:
   ```bash
   git clone https://github.com/ВАШ_НІКНЕЙМ/streamer-simulator-2.git
   cd streamer-simulator-2
   ```

2. **Встановіть залежності**:
   ```bash
   npm install
   ```

3. **Запустіть сервер розробки**:
   ```bash
   npm run dev
   ```

4. **Відкрийте у браузері**:
   Перейдіть за адресою `http://localhost:5173/`.

5. **Збірка для продакшену (Build)**:
   ```bash
   npm run build
   ```
